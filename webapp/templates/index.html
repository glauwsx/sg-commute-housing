SG 通勤租屋互動探索器

輸入你的上班地點，找出通勤最方便的租屋區域 — 公車直達、捷運直達、公司廠車三種方式都能算，也都能各自關掉。全程在這個介面操作，不需要跑任何指令。

1 LTA DataMall API Key

免費申請：datamall.lta.gov.sg → 註冊 → 申請 API Access Key（信箱收信）。貼進來按驗證，成功後會自動存到 .env，下次不用再輸入。

2 下載交通路網資料

公車站牌與路線來自 LTA DataMall（約 5,000 站牌 / 26,000 筆路線站序）；捷運與輕軌站點來自 OneMap（約 190 站）。只需下載一次，之後會快取在本機。

3 開始探索

資料就緒後就能進入互動地圖。上班地點、通勤方式、廠車點、半徑、接駁與單程時間上限全部都能在畫面上即時調整。
